# Ocularium

A medieval first-person game seen through a body-worn camera, for the web (WebGPU).

## Run

```sh
npm install
npm run dev
```

Open http://localhost:5199 in a recent Chrome or Edge and click to begin.

## Controls

| Input | Action |
|---|---|
| W A S D | Move |
| Shift | Run |
| C | Crouch |
| Space | Jump |
| Q / E | Lean |
| Mouse | Aim |
| Left button | Cut |
| Right button | Raise shield |
| F | Thrust |
| Esc | Pause |
